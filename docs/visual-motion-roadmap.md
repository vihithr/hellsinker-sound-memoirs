# Windows 播放演出：下一轮动效调整意图

2026-11-17 · 设计交接 / 待实施。范围：Windows 原生播放器的中央演出（F7）与左右侧翼（F8）。

**用户反馈：当前设计还不够动态，幅度和效果感受都不够。** 下一轮先不增加模式。目标是让人不看频谱数字，也能从画面看出重拍落在哪里、乐句何时抬升、声音怎样散去。原版字格、面板比例、主题配色和左右声道分工继续保留；原版模式作为对照，不改它的响应。

## 先把一个重音做好

现有星蚀把能量主要画成环边短线的长度，轨道本身按时间匀速运行；地层靠短历史频谱叠线；相位和侧翼多半在每帧已有的波形附近描线。因此即便局部每帧都变，远看构图的重量也可能没变。**工作假设**是缺少“大形变”和“起落的时间差”；这不是已经测出的音频故障。

第一轮用「星蚀＋折叠波形」试调。选一段先轻后重、鼓点干净的音乐，标出同一记重拍，反复从拍前两秒播到拍后两秒。期望看到三个时刻：拍前星环收紧；拍点到达的瞬间，环沿径向撑开、两翼出现宽截面；声音落下后，中央先收住，两翼的残影再消退。不要预演尚未发生的拍点，拍前的收紧来自前一声的自然衰减。

| 部位 | 下一步要试的变化 | 怎么判断值得留 |
| --- | --- | --- |
| 星蚀 | 用低频能量的上升量推整圈半径，中高频仍控制局部刻线。重拍靠轮廓位移表达，降低匀速公转的存在感。 | 缩到 1× 仍能辨出拍点；长音能托住环，但不会连续触发冲击。 |
| 地层 | 把新峰放在前景，给它足够高度；旧峰按真实时间往后走，靠遮挡、线距和主题色明度形成纵深。 | 单击能看到“一道峰经过”，连续鼓点能分开数；强段不糊成一块。 |
| 相位 | 保留左右声道真实几何，让新笔迹亮而清楚，旧笔迹分层衰减；缓慢调节增益，避免单帧峰值把后续轨迹突然压小。 | 单声道仍接近一条线，宽立体声才展开；轻声可见，静音不自转。 |
| 两翼 | 折叠波形优先拉开强弱的宽度差；双线带谱让起音拉开两条边、尾音合拢；点阵用亮区推进与回落代替整列同时翻亮。左右分别取声道包络。 | 强拍能用到翼宽的大部分，弱段仍有留白；只响一边时，另一边不会陪跳。固定 F8 后换 F7，侧翼选择保持不变。 |

## 实施顺序与验收

1. **先记录基线。** 固定主题、窗口倍率、曲目和起点，各录一段轻声、孤立重拍、持续强奏、左右声道明显分离的画面。每段 8–12 秒，保留同步音频。先看正常速度，再逐帧核对起音；静态截图只用来检查配色和边界。
2. **先调幅度，再调拖尾。** 从现有 43 段频谱及左右电平派生低频冲击、持续能量、分声道包络。快起慢落按毫秒计算，不按绘制帧数计算。首轮试调值：起音 20–40 ms，回落 180–350 ms；强拍时折叠波形试占单翼可用宽度的 70%–85%。这些是对照起点，不是每帧都要打满的指标。逐项 A/B，不同时加增益、加亮、加拖尾。
3. **通过一个组合再推广。** 先动 src/stage.cpp 的星环与 src/ui.cpp 的折叠侧翼。若确实需要跨模式共用的包络，再把计算放入 src/core/spectrum.*；不要为了一个演出的视觉增益改变原版频谱输出。绘制只读状态；暂停冻结、停止清空、跳转或换曲时丢弃旧残影。
4. **按听感决定保留。** 同一片段并排看旧版/新版：闭眼听到的重音，睁眼能否在同一拍看到明显位移？强奏后是否还有下一拍的余量？低音量段是否仍能看出哪边在响？最后在 ORIGINAL 和 DARK 各看一次，检查 1× 可读性与 2× 播放流畅度。若只是更亮、更忙，却没有更清楚的起落，撤回该项调整。

下一次可评审的交付：**一组同曲同起点、带声音的前后对照片段，一份实际采用的幅度/时间参数，以及保留或放弃每项变化的理由。** 先验收运动，再决定是否值得扩成新的演出模式。

## 候选演出：机械 DNA / HELIX

**视觉意图：让人看见一记重拍拧过整台机器。** 中央观察窗横放一根双股传动轴，两条有厚度的像素链由短横销相连。链条交叉时，前股完整，后股在交点断开两三个像素；横销跟着截面由宽变窄，转到侧面时几乎只剩一点。靠遮挡和宽度读出螺旋，不依赖渐变、霓虹或写实金属贴图。保留 SOUND MEMOIRS 标题、原版字格、面板框线和曲目区，模式标记用小字格 HELIX : 04。

**一拍的编排。** 轻声时，链条窄而松，两端轴承位置不动。低频起音先推动左端一节套筒，局部链节突然张开；这次扭转沿轴向右传递，已通过的位置逐节回弹。高频瞬态只点亮波头附近的一两枚铆钉。持续低音维持张力，但不反复发射冲击；静音时机构回中停住。试制从 12 节横销、约 160 ms 走完全轴开始，让波头跨越面板的动作在 1× 下也读得出来。

**两翼搭配：对置齿条 / RACK。** 每翼利用整栏高度布置一条齿轨和一块移动滑座。各自声道的快包络决定滑座行程，峰值留下一道短暂的刻度记号；两翼同时强时像一对推杆共同加载，单侧强时只推动该侧。不要把真实声道响应人为延迟来配合中央传播动画。F7 选择 HELIX 时，F8 的「跟随中央」采用 RACK；手选侧翼仍优先，RACK 也可以配其他中央模式。

**用色与试制边界。** 前股用当前主题的波形色，后股向面板底色混合，受力的少数横销借用频谱柱强调色；不另建一套配色。第一版只画中央链条，用孤立鼓点验证“起扭 → 传播 → 复位”。如果关掉铆钉闪光仍能看清冲击，再加两翼齿轨；若像两条同步摆动的正弦线，先修交叉遮挡和逐节相位差，不再堆粒子。最后用持续低音、连续鼓点和左右交替敲击复核，按上文的同曲录像标准决定是否进入 F7/F8 菜单。
